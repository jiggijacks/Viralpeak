## Overview

ViralPeak is an enterprise-grade social media growth platform that helps creators, brands, agencies, and businesses scale their online presence through secure, high-performance digital marketing services.

Designed with performance, automation, and reliability in mind, ViralPeak combines a modern user experience with enterprise-level infrastructure to deliver fast, scalable, and secure social growth solutions.

## Installation

```bash
git clone https://github.com/jiggijacks/viralpeak.git

cd viralpeak

composer install

cp .env.example .env

php artisan key: generate

php artisan migrate

php artisan serve
```
